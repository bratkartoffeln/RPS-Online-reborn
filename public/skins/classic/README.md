# Klassisch

Complete design package: skin.json, atlases, endgame/, gong/, audio/, source/.
Open preview.html on the game server to inspect artwork and listen to every cue.
Audio provenance and license: audio/SOURCES.json, audio/LICENSE.txt.
All four speech WAVs are synthesized locally with the Mandarin voice profile; no human voice recordings.
To add a design, copy this entire folder under a new ID, edit skin.json and add its entry to ../index.json. No client code changes are required.
See the repository GRAFIKSETS.md for schema, cue names, validation limits and asset regeneration commands.
